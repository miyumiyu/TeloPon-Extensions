# ✨ Счётчик новичков (FirstTimerCounter.py)

📥 **[Скачать FirstTimerCounter.py](https://raw.githubusercontent.com/miyumiyu/TeloPon-Extensions/main/plugins/FirstTimerCounter.py)**

Плагин, который обнаруживает в комментариях стрима ключевые слова вроде «впервые» или «привет» и **показывает накопленное число новых зрителей в постоянном статусном окне**.
Работает с любой платформой, предоставляющей комментарии — YouTube Live, Twitch, Niconico Live и т.д.

---

## 🌟 Основные функции

| Функция | Описание |
|---|---|
| Обнаружение новичков | Автоматически считает, когда настроенное ключевое слово встречается в комментарии |
| Защита от дубликатов | Один зритель учитывается только один раз (несколько сообщений «впервые» от одного пользователя не увеличивают счётчик) |
| Постоянный показ | Счётчик показывается в `window-status` (постоянное окно) |
| Редактируемые ключевые слова | Свободно добавляйте/удаляйте слова обнаружения (по одному на строку) |
| Кастомизация заголовка | Меняйте текст «✨ Новички» на любой |
| Очистка счётчика | Кнопка сброса для начала с нуля |
| Сохранение | Счёт и список известных пользователей сохраняются в `plugins/first_timer_counter.json` |
| Кроссплатформенность | Агрегирует уведомления от любых плагинов, получающих комментарии |

---

## ⚙️ Принцип работы

```
Плагин стриминг-платформы (например, YouTube Live+) получает комментарий
       ↓
 Вызывает broadcast_comment(text, author, source)
       ↓
 Вызывается FirstTimerCounter.on_comment_received()
       ↓
 1. Проверка, известен ли автор → если известен, пропускаем
 2. Сопоставление с ключевыми словами (без учёта регистра)
 3. Если совпало — увеличиваем счёт и добавляем автора в известные
 4. Показываем «✨ Новички: N» в window-status
```

Плагин использует **хук `on_comment_received`** (добавлен в v2.30b), поэтому модификация плагинов получения комментариев не требуется.

## 📦 Установка

1. Скачайте **«✨ Счётчик новичков»** из менеджера плагинов расширений
2. Файл будет автоматически размещён по пути `plugins/FirstTimerCounter.py`
3. Перезапустите TeloPon

## ⚙️ Настройка

### 1. Откройте панель настроек

В панели «Расширения» справа от главного экрана TeloPon нажмите кнопку **«⚙️ Настройки»** для **«✨ Счётчик новичков»**.

### 2. Параметры

| Параметр | Описание |
|---|---|
| **ВКЛ / ВЫКЛ** | Включить/выключить счётчик (при ВЫКЛ статусное окно также скрывается) |
| **Заголовок** | Текст, отображаемый в верхней строке телопа (по умолчанию: `✨ Новички`). Оставьте пустым, чтобы использовать значение из i18n |
| **Ключевые слова** | Слова, при наличии которых в комментарии срабатывает счётчик. По одному на строку. По умолчанию: `初見` / `おはつ` / `はじめまして` / `初コメ` / `first time` / `новичок` |
| **Текущий счёт** | Накопленное число обнаруженных новичков |
| **Известных пользователей** | Число авторов, отмеченных для предотвращения дубликатов (может не совпадать со счётом: включает авторов, чьи комментарии не совпали с ключевыми словами) |
| **🗑️ Очистить счётчик** | Сбросить и счёт, и список известных пользователей |
| **Закрыть** | Сохранить настройки и закрыть панель |

### 3. Регулировка положения/размера в OBS

Вы можете манипулировать статусным окном прямо в браузер-источнике OBS:

- **Перетаскивание** — Перемещение позиции
- **Колесо мыши** — Увеличение/уменьшение
- **Двойной клик** — Временное скрытие (показывается снова при следующем обновлении)

Эти настройки сохраняются в localStorage браузера (сохраняются даже после перезапуска OBS).

## 💡 Тестирование

### Сквозной тест

1. Запустите TeloPon в **режиме отладки**: `python telopon.py -d`
2. Подключите плагин получения комментариев (YouTube Live / Twitch и т.п.)
3. Опубликуйте тестовый комментарий (например, `привет, я впервые здесь!`)
4. В статусном окне должно появиться «✨ Новички: 1»

## 🔧 Продвинутое использование

### Добавление ключевых слов

Для многоязычных стримов:

```
初見
おはつ
はじめまして
初コメ
new here
first time
just joined
впервые здесь
привет всем
```

### Сброс известных пользователей для повторного счёта

Если хотите показывать «новичков этого стрима» по каждому стриму, нажмите кнопку **🗑️ Очистить счётчик** перед началом эфира.

### Постоянство между сессиями

По дизайну `stop()` не очищает статусное окно — счёт переносится в следующую сессию. Чтобы сбрасывать каждый стрим, очищайте вручную.

## 📋 Примеры использования

### TRPG-стримы

Приветствуйте новых исследователей и подсчитывайте их прибытие на экране. Визуализация счётчика создаёт атмосферу участия зрителей.

### Крупные коллаб-стримы

Для событий с бóльшим количеством новых зрителей, чем обычно, визуализируйте приток за день. После стрима можно подвести итог: «Сегодня к нам присоединилось N новичков!»

### Юбилей канала

Используйте как событие-веху для долго работающих стримов. Сбросьте счётчик перед эфиром, чтобы в реальном времени показывать новых зрителей.

---

## ⚠️ Замечания

- **Поддерживаемые платформы**: Плагины получения комментариев должны вызывать `broadcast_comment()`. Включённые в комплект плагины YouTube Live / YouTube Live+ / Twitch / Niconico Live поддерживают это (с v2.30b).
- **Регистр ключевых слов**: Не учитывается (`First Time` и `first time` обрабатываются одинаково)
- **Определение дубликатов**: Основано на имени автора комментария. Один человек, постящий с разных аккаунтов, будет считаться разными людьми.
- **Конфликт с другими использованиями статусного окна**: `window-status` имеет только один слот на странице. Использование вместе с другими постоянными отображениями (например, статус TRPG) приведёт к взаимной перезаписи.
