# ✨ 첫 방문자 카운터 (FirstTimerCounter.py)

📥 **[FirstTimerCounter.py 다운로드](https://raw.githubusercontent.com/miyumiyu/TeloPon-Extensions/main/plugins/FirstTimerCounter.py)**

방송 중 댓글에서 "처음", "첨" 같은 키워드를 감지하여 첫 방문 시청자의 누적 인원을 **상태 윈도우에 상시 표시**하는 플러그인입니다.
YouTube Live·Twitch·니코니코 생방송 등 댓글을 가져오는 모든 플랫폼에서 동작합니다.

---

## 🌟 주요 기능

| 기능 | 설명 |
|---|---|
| 첫 방문자 댓글 감지 | 설정한 키워드가 댓글에 포함되면 자동으로 카운트업 |
| 중복 방지 | 같은 시청자는 1회만 카운트(여러 번 "처음"이라고 해도 증가하지 않음) |
| 상시 표시 | 카운트를 `window-status`(영구 윈도우)에 표시 |
| 키워드 편집 | 감지할 단어를 자유롭게 추가·삭제(한 줄에 하나씩) |
| 헤더 문자 커스텀 | "✨ 첫 방문" 부분을 원하는 문자로 변경 가능 |
| 카운터 클리어 | 리셋 버튼으로 누적값을 0으로 초기화 |
| 영속화 | 카운트 값·기존 사용자 목록을 `plugins/first_timer_counter.json`에 저장 |
| 멀티플랫폼 | YouTube·Twitch·니코니코 등 댓글 수신 플러그인의 알림을 모두 집약 |

---

## ⚙️ 동작 구조

```
방송 플랫폼 플러그인(예: YouTube Live+)이 댓글 수신
       ↓
 broadcast_comment(text, author, source) 호출
       ↓
 FirstTimerCounter.on_comment_received() 호출
       ↓
 1. 기존 사용자인지 확인 → 기존이면 건너뛰기
 2. 키워드 매칭(대소문자 무시)
 3. 매칭되면 카운트+1, 사용자를 기존 목록에 추가
 4. window-status에 "✨ 첫 방문 N명" 표시·갱신
```

이 플러그인은 **`on_comment_received` 훅**(v2.30b에서 추가)을 사용하기 때문에 댓글 수신 플러그인을 수정할 필요가 없습니다.

---

## 📦 설치

1. 확장 플러그인 매니저에서 **"✨ 첫 방문자 카운터"** 다운로드
2. 자동으로 `plugins/FirstTimerCounter.py`에 배치됩니다
3. TeloPon 재시작

---

## ⚙️ 설정 방법

### 1. 설정 화면 열기

TeloPon 메인 화면 우측의 "확장 기능" 패널에서 **"✨ 첫 방문자 카운터"**의 **"⚙️ 설정"** 버튼을 클릭합니다.

### 2. 각 항목 설정

| 항목 | 설명 |
|---|---|
| **ON / OFF** | 체크하면 카운터 동작 시작(OFF로 하면 상태창도 사라짐) |
| **표시 헤더 문자** | 텔롭 상단에 표시되는 문자(기본: `✨ 첫 방문`). 비우면 i18n 기본값 사용 |
| **감지 키워드** | 댓글에 포함되면 반응할 키워드를 한 줄에 하나씩 나열. 기본값: `초견` / `おはつ` / `はじめまして` / `初コメ` / `first time` / `新人` |
| **현재 카운트** | 지금까지 감지된 첫 방문자 누적 인원수 |
| **알려진 사용자 수** | 중복 방지를 위해 기록 중인 작성자 수(카운트와 일치하지 않을 수 있음: 키워드 미매치 작성자도 포함될 수 있음) |
| **🗑️ 카운터 클리어** | 누적값과 기존 사용자를 모두 0으로 리셋 |
| **닫기** | 설정 저장 후 화면 닫기 |

### 3. 상태창 위치·크기 조정

OBS의 브라우저 소스에서 상태창을 직접 조작할 수 있습니다:

- **드래그** — 표시 위치 이동
- **마우스 휠** — 확대·축소
- **더블 클릭** — 일시 숨김(다음 업데이트 시 다시 표시)

이러한 조정은 브라우저의 로컬 스토리지에 저장됩니다(OBS 재시작해도 유지).

## 💡 동작 확인 테스트

### 종단 간 테스트

1. **디버그 모드**로 TeloPon 시작: `python telopon.py -d`
2. 댓글 수신 플러그인(YouTube Live / Twitch 등) 연결
3. 테스트 댓글 작성(예: `처음입니다!`)
4. 상태창에 "✨ 첫 방문 1명"이 표시되면 성공

## 🔧 고급 사용법

### 키워드 추가 예

영어 방송도 고려하는 경우:

```
초견
おはつ
はじめまして
初コメ
new here
first time
just joined
안녕하세요 처음 봅니다
```

### 기존 사용자를 리셋해서 재카운트

라이브 방송마다 "이번 방송의 첫 방문자"를 표시하려면 방송 시작 전에 **🗑️ 카운터 클리어** 버튼을 누릅니다.

### 영구 표시는 방송 종료 후에도 지속

`stop()`에서는 상태창을 지우지 않는 설계입니다(다음 시작 시 이전 값이 인계됨). 방송별로 리셋하려면 수동으로 클리어해 주세요.

## 📋 사용 예

### TRPG 플레이 방송

"첫 방문 탐색자를 환영합니다!"라고 내세워 첫 방문 댓글을 모음.
카운터를 화면에 띄워 시청자 참여형 분위기를 연출할 수 있습니다.

### 대규모 콜라보 방송

평소보다 신규 시청자가 많아지는 이벤트에서 당일 유입 수를 시각화.
방송 후 "오늘은 ◯◯명이나 되는 첫 방문자가 와주셨습니다!"라고 회고할 수 있습니다.

### 방송 1주년 기념

오래 운영해 온 방송의 마일스톤 이벤트로 사용.
방송 시작 전에 리셋해 두면 기념 방송에서의 신규 유입을 실시간으로 보여줄 수 있습니다.

---

## ⚠️ 사용상의 주의

- **지원 플랫폼**: 댓글 수신 플러그인이 `broadcast_comment()`를 호출하는 구현이어야 합니다. 동봉된 YouTube Live / YouTube Live+ / Twitch / 니코니코 생방송 플러그인은 대응 완료(v2.30b 이후).
- **키워드 대소문자**: 구별하지 않습니다(`First Time`과 `first time`은 동일하게 처리)
- **동일 시청자 판정**: 댓글 작성자명(author)으로 판정하므로 같은 사람이 다른 계정에서 작성하면 다른 사람으로 카운트됩니다
- **상태창 다른 용도와의 충돌**: `window-status`는 페이지에 1개뿐이므로 TRPG 상태 표시 등 다른 상시 표시 기능과 동시 사용 시 덮어쓰기 됩니다
