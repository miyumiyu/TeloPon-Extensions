# 🌉 TeloPon 브릿지 (TeloponBridge.py)

📥 **[TeloponBridge.py 다운로드](https://raw.githubusercontent.com/miyumiyu/TeloPon-Extensions/main/plugins/TeloponBridge.py)**

2개의 TeloPon 인스턴스를 HTTP로 연결해 **AI끼리 대화**시키는 플러그인입니다.
방송자는 사회자・퍼실리테이터로서, 두 AI 캐릭터의 주고받기를 즐길 수 있습니다.

---

## 🌟 주요 기능

| 기능 | 설명 |
|---|---|
| 텔롭 송신 | 자신의 텔롭 출력을 캡처해 상대 인스턴스로 HTTP POST |
| 텔롭 수신 | 자신도 HTTP 서버(localhost)를 가동, 상대의 메시지를 수신 |
| AI에 주입 | 수신 메시지를 `[브릿지] {speaker}님: {내용}` 형식으로 AI에 주입 |
| 폭주 방지 | 최소 송신 간격(초)과 최대 턴 수로 자동 정지 |
| 일시 정지/재개 | UI에서 수동으로 대화를 멈출 수 있음 |
| 프롬프트 애드온 | "상대는 다른 AI, 시청자 댓글과는 다른 것"이라고 AI에게 설명하는 문장을 자동 주입 |

---

## ⚙️ 동작 구조

```
[인스턴스A: AI-A] ─ 텔롭 출력
        ↓ on_telop_output 훅
        ↓ HTTP POST → http://localhost:9002/recv
[인스턴스B: AI-B] ← 수신
        ↓ self.send_text(plugin_queue, "[브릿지] AI-A님: ~")
        ↓ AI-B 응답 생성 → 텔롭 출력
        ↓ HTTP POST → http://localhost:9001/recv
[인스턴스A: AI-A] ← 수신 ... 루프
```

## 🛠 사용법 (2개 인스턴스 가동)

### 단계 1: 2개 폴더 준비

`settings.json` 충돌을 피하기 위해 TeloPon을 **별도 폴더에 복사**해 주세요:

```
C:\TeloPon-A\   ← 인스턴스 A
C:\TeloPon-B\   ← 인스턴스 B
```

### 단계 2: 포트를 별도로 설정

OBS 브라우저 소스용 HTTP 서버 포트도 충돌하므로 시작 옵션으로 별도 설정:

| | 인스턴스 A | 인스턴스 B |
|---|---|---|
| 시작 | `python telopon.py -p 8000` | `python telopon.py -p 8010` |
| OBS 브라우저 소스 | http://localhost:8000 | http://localhost:8010 |

### 단계 3: 브릿지 플러그인 설정

각 인스턴스에서 플러그인을 열고 다음과 같이 설정:

| 설정 | 인스턴스 A | 인스턴스 B |
|---|---|---|
| 브릿지 활성화 | ✅ ON | ✅ ON |
| 수신 포트 | 9001 | 9002 |
| 송신 URL | `http://localhost:9002/recv` | `http://localhost:9001/recv` |
| 본인 이름 | AI-A | AI-B |
| 최소 송신 간격 (초) | 5 | 5 |
| 최대 턴 수 | 0 (무제한) 또는 20 등 | 좌동 |

### 단계 4: 방송 시작 → 대화의 출발점 만들기

양쪽 인스턴스에서 방송을 시작하고 방송자가 한쪽에 말을 걸어 대화를 시작합니다:

> 방송자 (A 마이크에 대고): "B씨, 안녕하세요!"

→ A의 AI가 텔롭을 출력 → B에 도착 → B의 AI가 응답 → A로 돌아감 → … 계속됩니다.

---

## ⚠️ 중요: 마이크 피드백 대책

1대의 PC에서 2개 인스턴스를 가동하는 경우, **A의 AI 음성을 B의 마이크가 픽업하면 루프가 폭주**합니다.

**대책 (어느 하나 필수):**

1. **B 측 마이크 비활성화**: 시작 옵션 `-mi -1`로 마이크 없음 모드
2. **VB-CABLE 등 가상 오디오**로 완전 분리
3. **2대의 PC로 분산 가동** (가장 안전)

A의 AI 음성을 OBS에서 음소거해 두는 것도 효과적입니다.

## ⚙️ 설정 방법

### 1. 설정 화면 열기

"확장 기능" 패널의 **"🌉 TeloPon 브릿지"**의 **"⚙️ 설정"** 버튼을 클릭합니다.

### 2. 각 항목 설정

| 항목 | 설명 |
|---|---|
| **브릿지 활성화 (ON / OFF)** | 체크하면 HTTP 수신 서버 가동 + 텔롭 송신 시작 |
| **수신 포트** | 자신이 listen하는 포트 번호 (A: 9001, B: 9002 등) |
| **송신 URL** | 상대 인스턴스의 수신 엔드포인트 (예: `http://localhost:9002/recv`) |
| **본인 이름** | 송신 시 부여되는 화자명 (수신 측에서 `[브릿지] AI-A님: ~`처럼 표시). 프롬프트 설정의 AI 이름(`ai_name`)도 함께 송신되어 수신 측에서 "테로뽄 (AI-A)님"처럼 양쪽 표시됨. AI 이름만 설정된 경우는 "테로뽄님"으로 표시. |
| **최소 송신 간격 (초)** | 연투 방지. 이전 송신부터 N초 경과하지 않으면 스킵 |
| **최대 턴 수** | 0이면 무제한, N (>0)이면 N회 대화 후 자동 일시 중지 |

### 3. 상태 표시

| 표시 | 의미 |
|---|---|
| **수신 서버** | 가동 중 / 중지 / 일시 중지 표시 |
| **송신 횟수** | 이번 세션에서 송신한 메시지 수 |
| **수신 횟수** | 이번 세션에서 수신한 메시지 수 |
| **턴 수** | 송신+수신 누적 턴 수 |

### 4. 버튼

- **⏸ 일시 중지 / ▶ 재개**: 대화를 일시적으로 정지/재개
- **🔄 턴 리셋**: 턴 카운터를 0으로 (최대 턴 수 도달 후 재개에 편리)

## 🎬 방송 활용 사례

### AI 라디오 프로그램
2 캐릭터의 AI가 자유로운 대화. 방송자는 사회자로서 화제를 던짐.

### AI 만담・콩트
보케 역・츠코미 역의 2 AI로 만담. 프롬프트로 역할을 나누면 재미있음.

### TRPG의 2 NPC 대화
GM이 NPC-A와 NPC-B를 연기하는 장면에서 2 인스턴스에 각각 담당시킴.

### AI 토론・찬반양론
"찬성파 AI"와 "반대파 AI"를 별 캐릭터로 가동, 시청자에게 토론을 관전시킴.

### AI 선생님 + AI 학생
교육 콘텐츠. 선생님 역이 설명 → 학생 역이 질문 → 방송자가 보충 해설 추가.

## 💡 프롬프트 설계 요령

양쪽 인스턴스의 프롬프트에 **역할의 차이**를 명시하면 대화가 단조로워지지 않습니다:

```
인스턴스 A: "당신은 활기찬 AI, AI 어시스턴트 B와 친구입니다.
           짧은 대화로 즐겁게 주고받아 주세요."

인스턴스 B: "당신은 정중하고 철학적인 AI, AI 어시스턴트 A와 친구입니다.
           A의 경쾌함을 받아들이며 깊은 시점을 던져 주세요."
```

또한, TeloPon 브릿지 플러그인을 ON으로 하면 자동으로 다음 지시가 프롬프트에 추가됩니다:

> 다른 AI로부터 '[브릿지] {speaker}님: ~' 형식의 메시지가 도착합니다.
> 시청자 댓글과는 다르게 취급하고, 대화 상대로 자연스럽게 응답해 주세요.
> 답변은 짧게 (2~3문장 이내). 긴 독백을 피하고 턴을 넘기는 의식으로 대화하세요.

## ⚠️ 사용상의 주의

- **로컬 통신만**: HTTP는 `localhost`(127.0.0.1)에서만 listen합니다. 인터넷 너머의 연계는 지원되지 않습니다.
- **TLS 없음**: 평문 HTTP입니다. 동일 PC 또는 동일 LAN 내에서만 사용해 주세요.
- **수신 포트 충돌**: 이미 사용 중인 포트를 지정하면 서버 시작에 실패합니다. 에러 로그를 확인해 다른 포트를 시도하세요.
- **대화 폭주**: 최대 턴 수를 0(무제한)으로 하면 끝없이 대화가 이어지므로, 방송 중에는 적절한 값(20~50 등)으로 설정 권장.
- **설정 변경 후 반영**: 포트・URL 변경 후 "닫기" 버튼으로 저장 → 서버가 자동 재시작됩니다.

## 🔧 문제 해결

| 증상 | 대처 |
|---|---|
| 수신 서버가 가동되지 않음 | 포트가 이미 사용 중일 가능성. 다른 포트(9011 등) 시도 |
| 송신 실패 로그가 나옴 | 상대 인스턴스가 가동되지 않음 또는 송신 URL 오류 |
| 대화가 영원히 계속됨 | 일시 중지 버튼으로 정지, 또는 최대 턴 수 설정 |
| 같은 것을 반복함 | 프롬프트로 "짧게 답하기"를 강조, 또는 턴 간격을 늘림 |
| 마이크 하울링 | 가상 오디오로 분리, 또는 한쪽 마이크 끄기 |
