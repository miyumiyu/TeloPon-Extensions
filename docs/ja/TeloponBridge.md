# 🌉 TeloPon ブリッジ (TeloponBridge.py)

📥 **[TeloponBridge.py をダウンロード](https://raw.githubusercontent.com/miyumiyu/TeloPon-Extensions/main/plugins/TeloponBridge.py)**

2つの TeloPon インスタンスを HTTP で連携させて、**AI 同士で会話**させるプラグインです。
配信者は司会・ファシリテーターとして、2人の AI キャラクターの掛け合いを楽しめます。

---

## 🌟 主な機能

| 機能 | 説明 |
|---|---|
| テロップ送信 | 自身のテロップ出力を捕捉して、相手インスタンスへ HTTP POST |
| テロップ受信 | 自身も HTTP サーバー（localhost）を起動し、相手のメッセージを受信 |
| AIへの注入 | 受信メッセージを `[ブリッジ] {speaker}さん: {内容}` 形式で AI に注入 |
| 暴走防止 | 最低送信間隔（秒）と最大ターン数で自動停止 |
| 一時停止/再開 | UI から手動で会話を止められる |
| プロンプトアドオン | 「相手は別AI、視聴者コメントとは別物」と AI に説明する文を自動注入 |

---

## ⚙️ 動作の仕組み

```
[インスタンスA: AI-A] ─ テロップ出力
        ↓ on_telop_output フック
        ↓ HTTP POST → http://localhost:9002/recv
[インスタンスB: AI-B] ← 受信
        ↓ self.send_text(plugin_queue, "[ブリッジ] AI-Aさん: 〜")
        ↓ AI-B が応答生成 → テロップ出力
        ↓ HTTP POST → http://localhost:9001/recv
[インスタンスA: AI-A] ← 受信 ... ループ
```

---

## 📦 インストール

1. 拡張プラグインマネージャから **「🌉 TeloPon ブリッジ」** をダウンロード
2. 自動的に `plugins/TeloponBridge.py` に配置されます
3. TeloPon を再起動

## 🛠 使い方（2インスタンス起動）

### ステップ1: 2つのフォルダを準備

`settings.json` の競合を避けるため、TeloPon を**別フォルダにコピー**してください:

```
C:\TeloPon-A\   ← インスタンスA
C:\TeloPon-B\   ← インスタンスB
```

または同一フォルダで `settings.json` を別ファイルに（CLIオプション対応している場合）。

### ステップ2: ポートを別々に設定

OBSブラウザソース用のHTTPサーバーポートも競合するので、起動オプションで別々に:

| | インスタンスA | インスタンスB |
|---|---|---|
| 起動 | `python telopon.py -p 8000` | `python telopon.py -p 8010` |
| OBSブラウザソース | http://localhost:8000 | http://localhost:8010 |

### ステップ3: ブリッジプラグインの設定

各インスタンスでプラグインを開き、以下のように設定:

| 設定 | インスタンスA | インスタンスB |
|---|---|---|
| ブリッジ起動 | ✅ ON | ✅ ON |
| 受信ポート | 9001 | 9002 |
| 送信先URL | `http://localhost:9002/recv` | `http://localhost:9001/recv` |
| 自分の名前 | AI-A | AI-B |
| 最低送信間隔（秒） | 5 | 5 |
| 最大ターン数 | 0（無制限） or 20 等 | 同左 |

### ステップ4: 配信開始 → 会話の起点を作る

両方のインスタンスで配信を開始し、配信者がどちらか一方に話しかけて会話を始めます:

> 配信者（A側のマイクに向かって）: 「Bさん、こんにちは！」

→ A の AI がテロップを出す → B に届く → B の AI が応答 → A に戻る → … と続きます。

---

## ⚠️ 重要: マイクのフィードバック対策

1台のPCで2インスタンスを動かす場合、**A の AI 音声を B のマイクが拾うとループが暴走**します。

**対策（どれか必須）:**

1. **B 側のマイクを無効化**: 起動オプション `-mi -1` でマイクなしモード
2. **VB-CABLE 等の仮想オーディオ**で完全分離
3. **2台のPCに分けて起動**（最も安全）

A の AI 音声を OBS でミュートしておくのも有効です。

## ⚙️ 設定方法

### 1. 設定画面を開く

「拡張機能」パネルにある **「🌉 TeloPon ブリッジ」** の **「⚙️ 設定」** ボタンをクリックします。

### 2. 各項目を設定

| 項目 | 説明 |
|---|---|
| **ブリッジ起動 (ON / OFF)** | チェックを入れると HTTP 受信サーバー起動 + テロップ送信開始 |
| **受信ポート** | 自身が listen するポート番号（A: 9001, B: 9002 など） |
| **送信先URL** | 相手インスタンスの受信エンドポイント（例: `http://localhost:9002/recv`） |
| **自分の名前** | 送信時に付与される話者名（受信側で `[ブリッジ] AI-Aさん: 〜` のように表示） |
| **最低送信間隔（秒）** | 連投防止。前回送信から N 秒経過していないとスキップ |
| **最大ターン数** | 0 で無制限、N（>0）でN回会話したら自動一時停止 |

### 3. 状態表示

| 表示 | 意味 |
|---|---|
| **受信サーバー** | 起動中 / 停止中 / 一時停止中 を表示 |
| **送信回数** | このセッションで送信したメッセージ数 |
| **受信回数** | このセッションで受信したメッセージ数 |
| **ターン数** | 送信＋受信の累計ターン数 |

### 4. ボタン

- **⏸ 一時停止 / ▶ 再開**: 会話を一時的に止める／再開する
- **🔄 ターンリセット**: ターンカウンタを 0 に戻す（最大ターン数で停止した後の再開に便利）

## 🎬 配信のユースケース

### AIラジオ番組
2キャラのAIがフリートーク。配信者は司会者として話題を振る。

### AI漫才・コント
ボケ役・ツッコミ役の2AIで漫才。プロンプトで役割を分けると面白い。

### TRPG の2NPC会話
GM が NPC-A と NPC-B を演じ分けるシーンで、2インスタンスにそれぞれを担当させる。

### AI討論・賛否両論
「賛成派の AI」と「反対派の AI」を別キャラとして起動し、議論を視聴者に観戦してもらう。

### AI先生 + AI生徒
教育コンテンツ。先生役が説明 → 生徒役が質問 → 配信者は補足解説を入れる構成。

## 💡 プロンプト設計のコツ

両インスタンスのプロンプトに**役割の違い**を明示すると、会話が単調になりません:

```
インスタンスA: 「あなたは関西弁の元気なAI、AIアシスタントBと友達です。
              短い会話で楽しく掛け合ってください。」

インスタンスB: 「あなたは丁寧で哲学的なAI、AIアシスタントAと友達です。
              Aの軽妙さを受け止めつつ、深い視点を投げ返してください。」
```

また、TeloPon ブリッジ プラグインを ON にすると、自動的に以下の指示がプロンプトに追加されます:

> 別のAIから「[ブリッジ] {speaker}さん: 〜」形式でメッセージが届きます。
> 視聴者コメントとは別物として扱い、会話相手として自然に応答してください。
> 返答は短めに（2〜3文以内）。長い独白を避け、相手にターンを渡す意識で話してください。

## ⚠️ ご利用上の注意

- **ローカル通信のみ**: HTTP は `localhost`（127.0.0.1）でのみ listen します。インターネット越しの連携には対応していません。
- **TLS なし**: 平文 HTTP です。同一 PC または同一 LAN 内のみで使用してください。
- **受信ポートの競合**: 既に使われているポートを指定するとサーバー起動に失敗します。エラーログを確認して別ポートを試してください。
- **会話の暴走**: 最大ターン数を 0（無制限）にすると延々と会話が続くので、配信中は適切な値（20〜50など）に設定するのを推奨。
- **設定変更後の反映**: ポート・URL を変更したら「閉じる」ボタンで保存 → 自動的にサーバーが再起動します。

## 🔧 トラブルシューティング

| 症状 | 対処 |
|---|---|
| 受信サーバーが起動しない | ポートが既に使われている可能性。別ポート（9011 など）を試す |
| 送信失敗ログが出る | 相手インスタンスが起動していない or 送信先URLが間違っている |
| 会話が永遠に続く | 一時停止ボタンで止める、または最大ターン数を設定 |
| 同じことを繰り返す | プロンプトで「短く返す」を強調、またはターン間隔を伸ばす |
| マイクがハウる | 仮想オーディオで分離する、または片方のマイクを切る |
