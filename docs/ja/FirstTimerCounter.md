# ✨ 初見さんカウンター (FirstTimerCounter.py)

📥 **[FirstTimerCounter.py をダウンロード](https://raw.githubusercontent.com/miyumiyu/TeloPon-Extensions/main/plugins/FirstTimerCounter.py)**

配信中のコメントから「初見」「おはつ」などのキーワードを検出して、初見視聴者の累計人数を**ステータスウィンドウに常時表示**するプラグインです。
YouTube Live・Twitch・ニコニコ生放送など、コメントを取得する任意のプラットフォームで動作します。

---

## 🌟 主な機能

| 機能 | 説明 |
|---|---|
| 初見コメント検出 | 設定したキーワードがコメントに含まれると自動的にカウントアップ |
| 重複防止 | 同じ視聴者は1回のみカウント（複数回「初見」と書いても増えない） |
| 常時表示 | カウント数を `window-status`（永続ウィンドウ）に表示 |
| キーワード編集 | 検出する単語を自由に追加・削除（1行に1個） |
| 見出し文字カスタム | 「✨ 初見さん」の部分を好きな文字に変更可能 |
| カウンタークリア | リセットボタンで累計を0に戻せる |
| 永続化 | カウント値・既知ユーザーリストを `plugins/first_timer_counter.json` に保存 |
| マルチプラットフォーム | YouTube・Twitch・ニコニコ等、コメント受信プラグインからの通知を全て集約 |

---

## ⚙️ 動作の仕組み

```
配信プラットフォームプラグイン（例: YouTube Live+）がコメント受信
       ↓
 broadcast_comment(text, author, source) を呼ぶ
       ↓
 FirstTimerCounter.on_comment_received() が呼ばれる
       ↓
 1. 既知ユーザーかチェック → 既知ならスキップ
 2. キーワードマッチング（大文字小文字無視）
 3. マッチしたらカウント+1、ユーザーを既知リストに追加
 4. window-status に「✨ 初見さん N人」を表示・更新
```

このプラグインは **`on_comment_received` フック**（v2.30b で追加）を利用しているため、コメント取得プラグイン側を改造する必要はありません。

## 📦 インストール

1. 拡張プラグインマネージャから **「✨ 初見さんカウンター」** をダウンロード
2. 自動的に `plugins/FirstTimerCounter.py` に配置されます
3. TeloPon を再起動

---

## ⚙️ 設定方法

### 1. 設定画面を開く

TeloPon のメイン画面右側、「拡張機能」パネルにある **「✨ 初見さんカウンター」** の **「⚙️ 設定」** ボタンをクリックします。

### 2. 各項目を設定

| 項目 | 説明 |
|---|---|
| **ON / OFF** | チェックを入れるとカウンター動作開始（OFFにするとステータス枠も消える） |
| **表示する見出し文字** | テロップの上段に表示される文字（デフォルト: `✨ 初見さん`）。空にすると i18n のデフォルト値 |
| **検出キーワード** | コメントに含まれていたら反応するキーワードを1行に1個ずつ列挙。デフォルト: `初見` / `おはつ` / `はじめまして` / `初コメ` / `first time` / `新人` |
| **現在のカウント** | これまで検出した初見さんの累計人数 |
| **既知ユーザー数** | 重複防止のために記録している投稿者数（カウントと一致しないこともある: キーワード非マッチでも投稿があったユーザーが含まれる場合あり） |
| **🗑️ カウンタークリア** | 累計と既知ユーザーを全て0にリセット |
| **閉じる** | 設定を保存して画面を閉じる |

### 3. ステータス枠の表示位置・サイズ調整

OBS のブラウザソース上でステータス枠を直接操作できます:

- **ドラッグ** — 表示位置を移動
- **マウスホイール** — 拡大・縮小
- **ダブルクリック** — 一時的に非表示（次回更新時に再表示）

これらの調整はブラウザのローカルストレージに保存されます（OBSを再起動しても維持）。

## 💡 動作確認用テスト

### 単体動作テスト

1. **デバッグモード**で TeloPon を起動: `python telopon.py -d`
2. **手動操作パネル**から疑似コメントを送る（プラットフォームプラグインを経由しないので、コメント受信フックは発火しません）→ この方法では検証できないため次の方法を使う
3. 実際のコメントを取得するプラグイン（YouTube Live / Twitch 等）を接続
4. テストコメントを書き込む（`初見です！` など）
5. ステータス枠に「✨ 初見さん 1人」が表示されれば成功

### 視聴者がいない開発時のテスト

`plugin_loader.py` の手動投入機能や、コメント受信プラグインのテスト機能を使ってコメントを擬似発火する手段を併用してください。

## 🔧 高度な使い方

### キーワードを増やす例

英語配信を視野に入れる場合:

```
初見
おはつ
はじめまして
初コメ
new here
first time
just joined
hello everyone
```

### 既知ユーザーをリセットして再カウントする

ライブ配信ごとに「今回の初見さん」を表示したい場合は、配信開始前に **🗑️ カウンタークリア** ボタンを押します。

### 永続表示は配信終了後も継続

`stop()` ではステータス枠を消さない設計になっています（次回起動時に前回の値が引き継がれる）。配信ごとリセットしたい場合は手動でクリアしてください。

## 📋 使用例

### TRPGプレイ配信

「初見の探索者を歓迎します！」と謳って初見コメントを集める。
カウンターを画面に出すことで、視聴者参加型の盛り上がりを演出できます。

### 大型コラボ配信

普段の配信より新規視聴者が多くなるイベントで、当日の流入数を可視化。
配信後に「今日は◯◯人もの初見さんに来てもらいました！」と振り返りができます。

### 配信1周年記念

長く運営している配信のマイルストーンイベントとして使用。
リセットしてから配信を始めることで、記念配信での新規流入をリアルタイムで見せられます。

---

## ⚠️ ご利用上の注意

- **対応プラットフォーム**: コメント受信プラグインが `broadcast_comment()` を呼ぶ実装になっている必要があります。同梱の YouTube Live / YouTube Live+ / Twitch / ニコニコ生放送プラグインは対応済みです（v2.30b 以降）。
- **キーワードの大文字小文字**: 区別しません（`First Time` と `first time` は同じ扱い）
- **同一視聴者の判定**: コメント投稿者名（author）で判定するため、同じ人が別アカウントから投稿すると別人としてカウントされます
- **ステータス枠の他用途との競合**: `window-status` は1ページに1枠しかないため、TRPGステータス表示など他の常時表示機能と同時利用すると上書きされます
